# US-03-01 — Architecture du Convolutional Autoencoder

**Objectif.** Fournir une architecture de reconstruction commune aux futurs entraînements sur `bottle`, `transistor` et `hazelnut`. ST-03-01-01 livre le modèle PyTorch. ST-03-01-02 vérifie ses dimensions et un pas d’optimisation sur CPU.

## Architecture de référence

Chaque convolution utilise un noyau de 4 × 4, un stride de 2, un padding de 1 et un biais. Le décodeur reconstruit l’image à partir du seul bottleneck, sans connexion de saut. Pour un lot de `B` images, les dimensions du profil de référence sont les suivantes.

| Étape | Couche et activation | Sortie `[B,C,H,W]` |
|---|---|---|
| Entrée | RGB, flottants dans `[0,1]` | `[B,3,256,256]` |
| Encodeur 1 | Conv2d + ReLU | `[B,32,128,128]` |
| Encodeur 2 | Conv2d + ReLU | `[B,64,64,64]` |
| Encodeur 3 | Conv2d + ReLU | `[B,128,32,32]` |
| Bottleneck | Conv2d + ReLU | `[B,128,16,16]` |
| Décodeur 1 | ConvTranspose2d + ReLU | `[B,128,32,32]` |
| Décodeur 2 | ConvTranspose2d + ReLU | `[B,64,64,64]` |
| Décodeur 3 | ConvTranspose2d + ReLU | `[B,32,128,128]` |
| Reconstruction | ConvTranspose2d + Sigmoid | `[B,3,256,256]` |

Le modèle de référence compte **855 619 paramètres entraînables**. Les trois largeurs de l’encodeur et le nombre de canaux latents sont des entiers positifs configurables. La hauteur et la largeur doivent chacune être un multiple positif de 16. Le forward exige la taille déclarée et trois canaux RGB. [Implémentation](../../src/models/convolutional_autoencoder.py)

## Configuration et utilisation

Le fichier [cae_baseline.json](../../experiments/configs/cae_baseline.json) distingue les arguments de `CAEConfig` (rubrique `config`, seed 42) et les choix fixes décrits sous `fixed_architecture`. La MSE est calculée par l’appelant. Pour reproduire l’initialisation, appliquer la seed **avant** de construire le modèle.

Depuis la racine du dépôt, cet exemple charge la configuration et vérifie un forward sur CPU :

```python
import json
from pathlib import Path

import torch
from src.models.convolutional_autoencoder import CAEConfig, ConvolutionalAutoencoder

params = json.loads(Path("experiments/configs/cae_baseline.json").read_text("utf-8"))["config"]
params["image_size"] = tuple(params["image_size"])
params["encoder_channels"] = tuple(params["encoder_channels"])
config = CAEConfig(**params)
torch.manual_seed(config.seed)
model = ConvolutionalAutoencoder(config).eval()

images = torch.rand(1, 3, *config.image_size)
with torch.no_grad():
    reconstruction = model(images)
    mse = torch.nn.functional.mse_loss(reconstruction, images)
```

Pour les entraînements par catégorie, utiliser `MVTecTransform(size=config.image_size, profile="cae")` puis `batch["image"]` comme entrée et cible. La Sigmoid restitue la plage RGB `[0,1]`. Apprendre sur les normales de `train`, régler sur `val` et réserver le test officiel à l’évaluation finale. [API du pipeline](../epic-02/us-02-04.md) · [Protocole des splits](../epic-02/us-02-03.md)

## Validation CPU

Depuis la racine, dans le `.venv` du projet :

```powershell
python -m unittest discover -s tests/models -p "test_*.py" -v
python -m unittest discover -s tests/data -p "test_*.py" -v
```

- **7 tests CAE** couvrent la configuration, les dimensions intermédiaires, la forme et la plage de la reconstruction, les entrées invalides, la MSE, le backward, la mise à jour des poids et la reproductibilité de l’initialisation. **18 tests de données** couvrent les splits et le pipeline EPIC-02. [Tests du modèle](../../tests/models/test_convolutional_autoencoder.py)
- **Vérification à 256 × 256.** Un forward CPU avec un lot de taille 1 reproduit les dimensions du tableau.
- **Pas d’optimisation synthétique.** Avec Python 3.12.6, PyTorch 2.15.0+cpu, la seed 42, deux images aléatoires de 64 × 64 et Adam (`lr=0.001`), la MSE initiale vaut environ 0,084599. Les 16 tenseurs de gradients sont présents et finis. La somme de leurs valeurs absolues vaut environ 0,080236 et le pas modifie les poids.

Ces vérifications portent sur la mécanique du modèle à l’initialisation. La qualité de reconstruction sur MVTec AD, le choix de la capacité latente et les cartes d’anomalies restent à évaluer lors des expériences ultérieures.
