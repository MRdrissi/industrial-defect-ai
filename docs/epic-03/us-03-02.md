# US-03-02 — Entraînement et validation du CAE Bottle

**Epic :** EPIC-03 — Convolutional Autoencoder

**Branche d'intégration :** `epic/03-convolutional-autoencoder` 
**Expériences :** cae-bottle/EXP-001 et cae-bottle/EXP-002

## 1. Objectif

Entraîner un Convolutional Autoencoder (CAE) sur des images normales de bouteilles afin d'apprendre leur reconstruction, puis sauvegarder et vérifier les meilleurs poids.

Le modèle minimise la **Mean Squared Error (MSE)** entre l'image originale et sa reconstruction.

## 2. Dataset et architecture

| Élément | Configuration |
|---|---|
| Dataset | MVTec AD — `bottle` |
| Source Kaggle | `ipythonx/mvtec-ad`, version 2 |
| Train | 167 images normales |
| Validation | 42 images normales |
| Images | RGB, 256 × 256 |
| Modèle | ConvolutionalAutoencoder V1 |
| Architecture | Encodeur (32, 64, 128) → Bottleneck 128 → Décodeur |
| Paramètres | 855 619 |
| Optimiseur / Loss | Adam / MSELoss |
| Batch size / Learning rate | 16 / 0.001 |
| Seed | 42 |

Le découpage suit le manifeste `docs/data/us-02-03/bottle_manifest.csv`, issu de l'US-02-03.

**Le Test officiel n'est utilisé ni pour l'entraînement ni pour la sélection des checkpoints.**

## 3. Expériences et résultats

Deux entraînements ont été réalisés avec la même architecture et les mêmes données. Seuls les paramètres d'Early Stopping et la durée maximale changent.

| Indicateur | EXP-001 | EXP-002 |
|---|---:|---:|
| Maximum d'epochs | 100 | 500 |
| Epochs exécutées | 27 | 500 |
| Early Stopping — patience | 10 | 40 |
| Early Stopping — min_delta | 1e-4 | 1e-6 |
| Meilleure epoch | 25 | 495 |
| Meilleure Train MSE | 0.00232712 | 0.00037027 |
| **Meilleure Validation MSE** | **0.00230164** | **0.00036805** |
| Arrêt | Early Stopping | Max epochs |

**Résultat :** EXP-002 réduit la meilleure Validation MSE d'environ **84 %** par rapport à EXP-001.

EXP-002 est donc retenue comme **meilleur checkpoint de reconstruction Bottle** parmi ces deux expériences. Cela ne démontre pas encore sa performance en détection d'anomalies.

## 5. Restauration indépendante

**Notebook :** `notebooks/07-cae-bottle-restore-check.ipynb`

Les checkpoints ont également été organisés dans un dataset Kaggle unique : `cae-bottle-exp001-checkpoint`.

| Version du dataset | Checkpoint |
|---|---|
| Version 1 | EXP-001 |
| Version 2 | EXP-002 |

Pour vérifier une expérience :

1. Attacher MVTec AD version 2 et la version correspondante du dataset de checkpoints.
2. Sélectionner `EXPECTED_EXPERIMENT_ID` dans le notebook 07.
3. Vérifier le SHA-256 et charger les poids du CAE.
4. Recalculer la MSE sur les 42 images Validation, sans réentraînement.
5. Comparer le résultat à la métrique enregistrée.

Les rapports générés sont `EXP-001_restore_report.json` et `EXP-002_restore_report.json`. La vérification est considérée comme réussie lorsque le notebook termine sans erreur et que le rapport indique `OK`.
