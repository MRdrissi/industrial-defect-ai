# US-02-03 — Protocole Train / Validation / Test

**Epic :** 02 — Dataset & Experimental Protocol
**Branche :** `epic/02-data-preparation` · **Dataset :** MVTec AD (`ipythonx/mvtec-ad`)

## 1. Travail réalisé

Nous avons défini un **découpage reproductible** pour les trois catégories `bottle`, `hazelnut` et `transistor` :

- **Train :** 80 % des images normales de `train/good/`, pour apprendre la normalité.
- **Validation :** 20 % des mêmes images normales, pour sélectionner les paramètres et calibrer les seuils sans exploiter le test.
- **Test :** ensemble **officiel MVTec AD**, conservé intégralement (images normales, anormales et masques).

Le découpage utilise `seed=42`, des chemins triés avant mélange et `random.Random(seed)`. Les chemins enregistrés sont **relatifs à la racine du dataset** : aucun fichier image n'est copié ou modifié.

| Catégorie | Train | Validation | Test officiel |
|---|---:|---:|---:|
| bottle | 167 | 42 | 83 |
| hazelnut | 313 | 78 | 110 |
| transistor | 170 | 43 | 100 |
| **Total** | **650** | **163** | **293** |

**Total : 1 106 images**, réparties sans chevauchement de chemins. Les données de test ne doivent **jamais** servir à entraîner, sélectionner des hyperparamètres ou fixer les seuils.

## 4. Régénérer les manifestes

Il faut disposer du dataset MVTec AD avec sa structure originale. **Sur Kaggle, choisir un notebook CPU** et attacher le dataset `ipythonx/mvtec-ad` ; le téléchargement sur Windows n'est pas nécessaire.

Le module `split_dataset.py` doit être accessible à Python (importé depuis le dépôt ou ajouté comme *Input* Kaggle). Exemple **depuis la racine du dépôt** avec Python ; adapter `dataset_root` et `output_dir` à l'environnement :

```python
from pathlib import Path
from src.data.split_dataset import build_manifest, save_manifest

dataset_root = Path("/kaggle/input/datasets/ipythonx/mvtec-ad")
output_dir = Path("/kaggle/working/mvtec_splits_rebuilt")

for category in ("bottle", "hazelnut", "transistor"):
    rows = build_manifest(dataset_root, category, seed=42, validation_ratio=0.20)
    save_manifest(rows, output_dir / f"{category}_manifest.csv")
```

Sur Kaggle, si seul `split_dataset.py` est attaché comme *Input* (sans structure `src/`), ajouter son dossier à `sys.path` et utiliser `from split_dataset import build_manifest, save_manifest` à la place.

**Reproductibilité validée :** les trois CSV régénérés avec le module ont eu des SHA-256 **identiques octet pour octet** aux manifestes Kaggle d'origine. Comparer systématiquement les nouveaux hashes avec `split_protocol.json` avant de réutiliser ou remplacer les manifestes.

## 5. Consignes pour les US suivantes

- **US-02-04 — Prétraitement :** lire `image_path` depuis les manifestes, puis le résoudre sous la racine MVTec ; utiliser les splits sans les recalculer.
- **CAE / PatchCore :** apprendre uniquement sur `train`, régler sur `val`, évaluer une fois sur `test` ; utiliser `mask_path` pour l'évaluation de la localisation.
- **Attention :** la validation contient uniquement des images normales : elle ne permet pas de maximiser directement un F1 d'anomalies. Les tests vérifient l'absence de chevauchement **par chemin**, pas l'absence absolue de doublons visuels.

**Ne pas committer les images MVTec AD** : seuls le code, les tests, les manifestes et la documentation sont versionnés.
