# US-02-04 — Pipeline commun de prétraitement MVTec AD

**Objectif.** Fournir au CAE et à PatchCore les mêmes échantillons de `bottle`, `hazelnut` et `transistor`, avec un prétraitement configurable et un masque aligné sur chaque image RGB.

## 1. API et protocole

| Module | Interface | Responsabilité |
|---|---|---|
| [mvtec_dataset.py](../../src/data/mvtec_dataset.py) | `MVTecDataset(dataset_root, manifest_path, category, split, transform=None)` | Vérifie le schéma et les labels du CSV, sélectionne le split demandé et décode les PNG à la lecture d’un échantillon. |
| [transforms.py](../../src/data/transforms.py) | `MVTecTransform(size=(256, 256), profile="cae", mean=…, std=…)` | Applique la même taille cible `(hauteur, largeur)` à l’image et au masque. |
| [dataloaders.py](../../src/data/dataloaders.py) | `create_dataloader(dataset, batch_size=16, num_workers=0, seed=42)` | Mélange le train avec un générateur initialisé par la seed. Validation et test conservent l’ordre du CSV. Le dernier lot est conservé. |

Utiliser le [manifeste figé](../data/us-02-03/) de la catégorie. Ses colonnes sont `category,split,image_path,label,defect_type,mask_path`. Les chemins sont relatifs à `dataset_root`. Les images de `val` résident physiquement sous `train/good/` et sont sélectionnées par la colonne `split`. Le CAE et la banque mémoire PatchCore apprennent sur `train`. La validation normale sert aux réglages et aux seuils. Le test officiel est réservé à l’évaluation finale. [Protocole US-02-03](us-02-03.md)

Chaque échantillon est un dictionnaire avec `image` (RGB, `float32 [3,H,W]` avec les profils fournis), `mask` (`bool [1,H,W]`), `label` (entier, 0 normal ou 1 anomalie), `category`, `defect_type` et `image_path` (chemin relatif). Une normale reçoit un masque nul. Pour une anomalie, le chargeur ouvre le `mask_path` du CSV et vérifie la taille source. Un masque manquant ou une taille incompatible déclenche une erreur.

## 2. Réutilisation depuis la racine du dépôt

Dans un environnement disposant de PyTorch, torchvision et Pillow, définir `MVTEC_ROOT` sur le dossier qui contient directement les répertoires des catégories. Les chemins `/kaggle/input/…` et `/kaggle/working/…` du notebook appartiennent à sa session Kaggle.

```python
import os
from pathlib import Path

from src.data.dataloaders import create_dataloader
from src.data.mvtec_dataset import MVTecDataset
from src.data.transforms import MVTecTransform

category = "bottle"
dataset = MVTecDataset(
    dataset_root=Path(os.environ["MVTEC_ROOT"]),
    manifest_path=Path("docs/data/us-02-03") / f"{category}_manifest.csv",
    category=category,
    split="train",
    transform=MVTecTransform(size=(256, 256), profile="cae"),
)
batch = next(iter(create_dataloader(dataset, batch_size=16)))
```

- **CAE** — L’image est redimensionnée en bilinéaire et ramenée dans `[0,1]`. Avec `transform=None`, l’échantillon conserve sa résolution source.
- **PatchCore** — Utiliser `profile="patchcore"`. Après la mise à l’échelle, le profil applique `(x - mean) / std` par canal RGB. Les valeurs par défaut sont `(0.485, 0.456, 0.406)` et `(0.229, 0.224, 0.225)`. Vérifier ces paramètres avec les poids du backbone retenu et éviter une seconde normalisation.
- **Masques** — Les deux profils utilisent le plus proche voisin et un seuil à 127 pour produire un masque booléen. La normalisation de l’image laisse le masque intact.
