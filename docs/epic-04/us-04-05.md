# US-04-05 — Inférence et restauration des artefacts PatchCore

**Branche :** `epic/04-patchcore`  
**Expérience :** `patchcore-bottle/EXP-003`

## 1. Objectif

Implémenter une API Python générique permettant de restaurer un modèle PatchCore et de produire un score brut ainsi qu'une carte d'anomalie pour une image.

Cette API est destinée à être réutilisée par le pipeline d'évaluation scientifique de l'EPIC-05 et l'application web de l'EPIC-06.

## 2. Implémentation

Le module `src/inference/patchcore_inference.py` fournit :

- `load_patchcore()` : chargement du backbone et de la Memory Bank depuis un checkpoint.
- `PatchCoreInference.from_checkpoint()` : initialisation du moteur d'inférence.
- `predict()` : inférence sur une image.
- `predict_batch()` : inférence sur plusieurs images.
- `PatchCoreInferenceResult` : résultat compatible avec les champs communs du contrat CAE.

La restauration utilise `pre_trained=False`, `torch.load(..., weights_only=True)` et `load_state_dict(..., strict=True)`.

Aucun réentraînement ni recalcul du Coreset n'est effectué.

## 3. Tests unitaires

Fichier : `tests/inference/test_patchcore_inference.py`

**Résultat : 11 tests réussis**, sous Windows avec Python 3.12.10 et pytest 9.2.0.

Les tests vérifient le contrat de sortie, les dimensions, l'inférence par batch, la sérialisation et les erreurs d'entrée.

Ils utilisent un modèle factice afin de ne pas dépendre d'Anomalib ou d'un checkpoint réel.

## 4. Validation réelle — Bottle

L'expérience `patchcore-bottle/EXP-003` valide l'API sur Kaggle CPU à partir du checkpoint de l'US-04-02.

- Catégorie : Bottle.
- Dataset : MVTec AD v2.
- Image : `bottle/train/good/002.png`, split Validation.
- Backbone : Wide ResNet-50-2.
- Memory Bank : 1 710 × 1 536.
- Carte d'anomalie : 256 × 256.
- Notebook : `16-patchcore-inference-api-check.ipynb`.

## 5. Limites et intégration future

L'API est conçue pour les catégories Bottle, Hazelnut et Transistor, mais seule Bottle a été validée sur Kaggle dans cette US.

Les tests réels des deux autres catégories restent à effectuer dès que leurs checkpoints seront disponibles.

Les scores sont bruts, non calibrés. Le choix des seuils et les métriques scientifiques relèvent de l'EPIC-05.

L'intégration dans Streamlit et le registre des modèles relèvent de l'EPIC-06.
